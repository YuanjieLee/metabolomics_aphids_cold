Overview

This repository contains datasets related to the manuscript entitled "Cold survival in aphids: linking species-specific metabolic responses to cold tolerance". 

Data S1_aphid_surv.csv: Data file containing survival data for cold treatment. This is used as input for Lethal median time computating and survival curve plot.

Data S2_metabolites_data.csv: Data file containing metabolites measurements for Experiment 1 and 2. This is used as input for the PCA analysis and the univariate analysis.
